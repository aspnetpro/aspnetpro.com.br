// a missão

Oito passos, cerca de 90 minutos.

  1. 0Linha de baseseu gargalo5 minClone o template e rode os testes. Você só sabe se o agente quebrou algo se souber que estava verde antes.
  2. 1Explorarseu gargalo10 minO agente explica a arquitetura sem você explicar nada: ele leu o CLAUDE.md.
  3. 2Rodada Aseu gargalo15 minUm prompt só, aceita o que vier, e conta quantas decisões ele tomou sozinho.
  4. 3Especificarseu gargalo15 min/spec te entrevista antes de escrever qualquer código.
  5. 4Planejarseu gargalo10 min/plano propõe etapas pequenas, cada uma com os seus testes.
  6. 5Testes primeiroseu gargalo15 minCada teste falha pelo motivo certo antes da implementação.
  7. 6Verificarseu gargalo15 min/verificar revisa spec, testes, código e segurança. Depois, você lê o diff.
  8. 7Compararseu gargalo5 mingit diff rodada-a rodada-b e a ficha de comparação.

// perguntas frequentes

Antes de clonar.

É gratuito?

Sim. O repositório é seu depois do "Use this template".

Preciso pagar o Claude?

O Claude Code precisa de uma conta com acesso a ele (plano pago) ou de uma chave da API. O kit em si é gratuito.

Funciona com Codex, Cursor ou Copilot?

Os comandos /spec, /plano e /verificar são do Claude Code. O método funciona em qualquer agente: são prompts em português que você pode levar para a ferramenta que usa.

Preciso saber muito de ASP.NET?

O básico de C# e de API basta. O projeto tem cerca de 15 arquivos.

E se o agente fizer algo diferente do vídeo?

Vai fazer. O resultado da Rodada A muda a cada vez, e é justamente isso que a ficha de comparação mede.
