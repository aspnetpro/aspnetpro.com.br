// o problema

Você já sabe que IA agêntica existe.
O problema é aplicar no seu projeto.

O processo mais comum é sempre o mesmo:

→ Abre o Claude ou o ChatGPT → Cola o problema → Pede para implementar → Torce para não quebrar nada

Funciona. Até o projeto crescer.

Depois vêm os sintomas
✕O agente perde contexto depois de alguns arquivos
✕O código ignora a arquitetura que você levou meses para definir
✕Cada interação toma uma decisão diferente
✕Você passa mais tempo revisando do que teria levado escrevendo à mão
A causa raiz
→O problema não é a IA. É que ela está codando sem passar pelo processo de engenharia antes.
→Sem especificação, sem decisão arquitetural registrada e sem plano, o agente adivinha. E adivinhar não escala.
// o que 10x significa

Tem dois tipos de velocidade com IA.

A primeira é velocidade sem engenharia: o agente gera código rápido, você revisa, corrige, refaz. Parece produtividade nas primeiras horas — e vira retrabalho na semana seguinte.

A segunda é velocidade com engenharia: o agente executa dentro de uma especificação, de uma arquitetura e de um plano que você definiu antes. O que sai já nasce alinhado.

É a segunda que você aprende aqui.

Neste Bootcamp, 10x não significa escrever 10x mais código. Significa entregar em dias o que hoje se arrasta por semanas de retrabalho — sem abrir mão de arquitetura, qualidade e segurança.

Porque no fim, velocidade que quebra o projeto não é velocidade. É dívida técnica mais rápida.

🏗️
Arquitetura

O agente respeita a estrutura do projeto — não quebra o que você levou meses para definir.

✅
Qualidade

Cada entrega passa por review antes de finalizar. Sem “código que funciona mas eu não sei por quê”.

🔒
Segurança

Decisões registradas, contexto controlado e rastreabilidade do requisito até o teste. Você sabe de onde veio cada linha.
