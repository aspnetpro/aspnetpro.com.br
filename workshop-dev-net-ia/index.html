A diferença entre vibe coding e SDD

Vibe coding · sem plano de vooSDD · com plano de voo
Prompt → código diretoSpec → plano → testes → código → verificação
O agente decide as regras de negócio sozinhoVocê decide, e a spec registra
Teste depois, se tiverTestes primeiro: eles definem o que é pronto
Revisão no olhoVerificação com checklist e skill
// sem jargão solto

4 palavras que você vai usar nas duas noites.

›Spec: o plano de voo. As regras de negócio decididas antes do código
›Permissão: os limites. O que o agente faz sozinho, o que pergunta e o que nunca faz
›Skill: um procedimento que o agente sabe seguir quando o pedido pede
›MCP: um instrumento. Dá ao agente acesso ao GitHub, à documentação, ao banco
